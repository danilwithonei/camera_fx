# Camera FX

Браузерное расширение, которое накладывает эффекты на веб-камеру прямо на сайте (Google Meet, Zoom Web, Discord и т.п.). Сайт получает уже обработанное видео, звук проходит без изменений.

## Эффекты

- **Ч/Б** — черно-белое изображение.
- **Линза** — искажение «рыбий глаз» вокруг носа.
- **PS1 3D** — лицо на экране низкополигональной модели в стиле PlayStation 1 (телевизор, автомат, голова, машина, стиралка).
- **Цензура глаз** — черная полоса на глазах.
- **Пиксельное лицо** — пикселизация лица.
- **Картинка на глаза** — своя картинка поверх глаз.
- **Letterbox** — киношные черные полосы, опционально Ч/Б.
- **Зелёный экран** — видео с хромакеем поверх камеры (можно загрузить своё).

Лицо отслеживается локально через MediaPipe Face Landmarker, ничего не отправляется в сеть.

## Установка

**Chrome / Edge (111+)**
1. Откройте `chrome://extensions/`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.

**Firefox (128+)**
1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите «Загрузить временное дополнение» и выберите `manifest.json`.
3. Разрешите расширению доступ к сайтам (в настройках расширения).

После установки перезагрузите вкладку с сайтом и заново включите камеру.

## Как устроено

| Файл | Назначение |
| --- | --- |
| `inject.js` | Запускается в контексте страницы до её скриптов, подменяет `getUserMedia` и рисует эффекты на canvas |
| `content.js` | Передаёт настройки из `chrome.storage` в `inject.js` |
| `popup.html`, `popup.js` | Окно настроек |
| `lib/` | Three.js и MediaPipe (локально, чтобы не зависеть от CSP сайтов) |
| `models/` | Модель MediaPipe для лица |
| `models3d/` | 3D-модели для эффекта PS1 |
| `green_screens/` | Видео по умолчанию для зелёного экрана |
| `image.png` | Картинка по умолчанию для «Картинки на глаза» |
